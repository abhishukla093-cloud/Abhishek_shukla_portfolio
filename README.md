# Abhishek Shukla — Next.js + TypeScript Portfolio

## Stack
- Next.js
- TypeScript
- React
- Tailwind CSS
- Responsive dark premium UI

## Included
- Professional profile photo
- Data Engineer-focused skills
- Data engineering architecture
- AI / model evaluation work
- Project case-study pages
- StockSense AI PRD PDF
- SupportPilot AI PRD PDF
- Professional resume PDF

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy
Recommended: GitHub + Vercel.
1. Create a GitHub repository.
2. Upload this project.
3. Import the repository into Vercel.
4. Deploy.
5. Replace placeholder email, LinkedIn and GitHub URLs before publishing.
